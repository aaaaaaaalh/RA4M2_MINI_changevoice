# RA4M2 MINI VoiceLab

基于 RA4M2MINI 与 MATLAB R2025b 的语音采集、降噪和变声实验。当前基线版本：**v0.2.0**。

麦克风 AO → P001/ADC → 16 kHz 采样 → CH340E 串口 → MATLAB 降噪、变声和电脑播放。

## 已实现

- 电脑麦克风和板卡串口两种输入。
- 实时变声、录音后处理、音频导入、原声/结果试听与 WAV 导出。
- 原声、女声风格、男声风格、老人、儿童、机器人；保持语速与时长。
- 噪声学习与谱减降噪、音高、明亮度及输出增益设置。
- 时域波形、32柱频谱、RMS；串口同步、序号、丢包和 ADC 电平诊断。

## 使用

详细接线、编译、烧录和验证步骤见 [START_HERE.md](START_HERE.md)。

1. 使用 e² studio/FSP 6.6.0 编译 `firmware/RA4M2MINI`，烧录并恢复正常运行模式。
2. MATLAB 当前文件夹切换到 `matlab`，运行 `selftest_serial`。
3. 按实际设备端口运行 `report = board_probe("COM4",5);`，COM4仅为示例。
4. 运行 `app = VoiceLab;`，选择板卡串口输入与耳机输出。

工具箱：Audio Toolbox、DSP System Toolbox、Signal Processing Toolbox。完整固件源码和配套 FSP/CMSIS 文件一并保留，构建产物不纳入版本控制。

## 实测记录（2026-09-30）

用户已成功编译、烧录并完成板卡链路测试。一次诊断收到313包，Lost=0、BadSync=0；音频5.008秒，墙钟5.004秒。用户确认实时运行无明显断音或延迟累积，男女声效果变化明显且清楚连续。

参数经验：用户当前认可降噪强度3、增益+3 dB，近距离说话。它们是使用建议，不是本次对程序默认值的修改。根据环境重新学习噪声。

已知限制：触碰导线会产生明显杂音，未确认具体电气原因；固定板卡与导线、避免触碰时噪声可接受。实时使用耳机。此版本的完整目标编译与硬件测试由用户完成，开发环境只执行了静态检查及模拟接口的C逻辑测试。
