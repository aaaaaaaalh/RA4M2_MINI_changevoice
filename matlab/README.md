# VoiceLab 中文操作说明

板卡接入请先阅读上一层 REALTIME_START_HERE.md；本说明主要介绍共用的变声操作。

本项目实现 MATLAB 电脑端语音采集、降噪、固定风格变声和分析界面。目标环境为 Windows 11、MATLAB R2025b，安装 Audio Toolbox、DSP System Toolbox、Signal Processing Toolbox。

## 启动

1. 完整解压压缩包，保留包内 matlab、python 文件夹和根目录启动脚本。
2. 在 MATLAB“当前文件夹”中打开这个文件夹。
3. 先运行 `selftest_voicelab`，检查不依赖麦克风的算法。
4. 再运行 `app = VoiceLab;` 打开界面。

## 实时变声

戴好耳机，选择“实时变声”，选好输入和输出设备，选音色并调整参数，点击“开始实时 / 开始录音”。点击“停止”后，可对比播放和保存本次原声、处理结果。输入输出默认走系统默认音频设备；输出设备也用于离线试听。

录制和处理期间参数锁定。修改效果时先停止，再调整并重新开始。参数数值框支持小数；音高以半音为单位，正数升高、负数降低。实时算法为有状态的双延时交叉淡化，可能有轻微调制感；离线算法更适合仔细比较音质。实时音频保持吞吐速率，不改变语速；保存的是实时流，包含启动延迟，不做未知设备延迟的自动对齐。说话结束后等待约半秒再停止，以保留缓冲中的尾音。

## 录音后变声

选择“录音后变声”，点击开始录音，再停止；或者点击“导入音频”。支持的文件由 audioread 决定，常用 WAV、MP3、FLAC、M4A。多声道取平均后转为单声道，重采样为 16 kHz。

调整音色和参数，点击“执行离线变声”。每次都从原声重新处理，不叠加前一次效果。可播放原声与处理结果，导出 16 kHz、16-bit PCM WAV。离线输出样本数与输入完全一致；升降调不是改变播放采样率。单次录制和导入最长 5 分钟。导入或新录音会替换内存中的上一段音频，请先导出要保留的结果。

## 降噪

先点击“学习环境噪声（1秒）”，保持安静，采集当前麦克风的背景噪声。学习完成后勾选“开启谱减降噪”。默认 α=1.5，越大抑制越强，也越容易损伤语音；谱地板 β=0.04。更换输入设备或刷新设备会清空噪声模型；环境变化时应重新学习。噪声模型在本次应用运行中保留，未保存到磁盘。

离线文件的噪声不一定与当前麦克风一致：不一致时请关闭降噪。此版本未提供从导入文件选取噪声片段的功能，也不自动把文件开头当作噪声。算法采用固定学习到的噪声功率谱，适合相对稳定的风扇/底噪，不保证能去掉音乐或其他人的说话声。

## 音色与分析

预设包括原声、女声风格、男声风格、老人、儿童、机器人。预设是音高与频谱塑形效果，不是特定人物克隆。原声模式仍经过基础高低通、用户增益与输出限幅；导出原声按钮保存未经过这些效果的采集数据。

“保留共振峰”仅作用于离线变调；开启后更倾向保留原说话人的声道特征，关闭时音色变化较明显。老人效果包含轻微 5 Hz 幅度颤动；机器人默认载波 130 Hz。

实时波形显示最近约 1 秒，离线波形显示整段（显示点数最多 2500）。频谱始终显示传入片段最后 512 点，即最后 32 ms，不是整段平均频谱；如果文件末尾静音，离线频谱也会低。32 柱每柱聚合 8 个正频率 bin 的最大幅值，覆盖 0～8 kHz；柱坐标为名义频带中心。频谱采用 Hann 相干增益归一化，不按每帧峰值归一化。RMS 与频谱是两种不同指标：满幅正弦的 RMS 约 -3.01 dBFS、频谱峰约 0 dBFS。

状态栏报告输入丢失、输出欠载的样本数，不是串口丢包数。频谱约每 150 ms 刷新一次。实时端到端延迟包含声卡、驱动和算法缓冲，尚未实测。

## 测试步骤

1. 运行 selftest_voicelab，检查分块重建、降噪、音高方向、长度保持、机器人边带、静音和实时算法调用。
2. 打开界面，录音 5～10 秒，停止后试听原声。确认正确的麦克风和耳机设备。
3. 同一段语音分别使用男声、女声、儿童、老人和机器人，试听并导出；检查时长相同。
4. 学习噪声后，比较原声、仅降噪、降噪加变声；观察背景噪声和可懂度。
5. 实时运行至少 30 秒，记录丢失/欠载，检查是否有明显断续；关闭界面后重新打开验证设备已释放。
6. 播放期间点击停止；录音期间关闭窗口；导入短音频、静音文件，检查无崩溃。
7. 修改增益，确认频谱电平会随幅度变化。可使用 1 kHz 正弦检查主柱位置。

## 排错

- 音频设备启动失败：在 Windows 中允许桌面应用访问麦克风，关闭占用同一设备的软件，刷新设备并重新选择。此版使用默认驱动并请求 16 kHz；不兼容的声卡需要本机调整驱动或增加 48→16 kHz 采集适配。
- 找不到 audiopluginexample.PitchShifter：检查 Audio Toolbox 安装及 `which audiopluginexample.PitchShifter`，不要通过修改播放速度替代变调。
- 声音过小：先检查系统输入音量，再逐步调高输出增益。过大输入造成的削顶无法由后处理恢复。
- 啸叫：使用耳机，减少麦克风对扬声器的回采。
- 欠载不断增长：关闭不必要程序，先测试不降噪的原声。把 VoiceLab.m 内绘图间隔 `0.15` 改为 `0.25` 可以减少绘图开销；仍不稳定需要根据声卡调整音频缓冲。
- 离线取消：降噪循环可中断，shiftPitch 单次调用只能在计算返回后响应停止。
